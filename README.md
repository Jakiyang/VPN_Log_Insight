# VPN Log Insight

VPN 日志汇总报表生成工具。打开 `.html` 文件，拖入/选择 VPN 日志 CSV，即可一键生成交互式汇总报表。

## 特性

- **纯前端**：单文件 HTML，无需后端、无需安装
- **拖放上传**：支持文件拖入和点击选择
- **多设备去重**：同一用户跨设备的并发会话时间取并集，避免多设备在线时长重复累加
- **跨零点拆分**：会话跨越零点时，零点前的在线时间正确归入前一个自然日
- **同时在线人数**：按 (用户, 日期) 唯一对统计每小时的平均同时在线人数
- **交互式图表**：每日趋势（柱状图+曲线图）、每小时趋势双轴图

## 使用

1. 双击打开 `VPN报表工具.html`
2. 拖入或选择 VPN 日志 CSV 文件
3. 等待处理完成，自动生成报表

## 报表内容

1. 概览卡片：统计日期起止、统计天数、独立用户数、总连接时长、用户日均连接时长
2. 用户每日平均连接时长汇总（按活跃天数/活跃日均时长降序）
3. 部门每日连接时长汇总（含日人均连接时长）
4. 每日连接趋势（总时长柱状图 + 独立用户数曲线图）
5. 每小时连接趋势（平均登录次数 + 平均同时在线人数）
6. 操作系统与接入城市分布（并排展示）

## CSV 格式要求

登录/注销日志，注销记录的描述字段需含 `onlineTime`（秒），例如：
```json
{"onlineTime":717,"currentSid":"...","logOutSid":"...","logOutPlatform":"Windows"}
```

## 技术说明

- 编码：UTF-8 with BOM
- 核心逻辑：单文件内嵌 JavaScript
- 图表：内联 SVG
